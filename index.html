01 About

What I spend my time on

I build production AI systems and the enterprise integration platforms underneath them — the kind that have to survive HIPAA audits, not just demos.

Agentic AI & LLM Orchestration. Building production multi-agent workflows with Google ADK, LangChain, and LangGraph. Implementing RAG pipelines with Chroma and Vertex AI — going well beyond proof-of-concept into HIPAA-compliant, enterprise-deployed AI systems serving real clinical operations teams. Hands-on with Pydantic AI and LLMOps tooling. Architecting AI Gateway patterns on Kong AI Gateway for safe LLM traffic routing — embeddings, chat completions, and reasoning API endpoints, plus MCP and A2A (agent-to-agent) protocol traffic — with prompt governance and model endpoint security in production.

Data Engineering for AI. Databricks and PySpark pipelines preparing and transforming structured healthcare data for retrieval and natural-language querying. Apache Airflow orchestration across multi-source data ingestion frameworks unifying records for 50M+ members. This is the unglamorous layer that makes the AI layer actually trustworthy.

MuleSoft & API-Led Integration. MuleSoft (5x Certified: Platform Architect, Integration Architect, Developer), CloudHub 2.0, Runtime Fabric, and API-led connectivity across 100+ APIs and 50M+ daily transactions at 99.99% uptime. Camunda BPM/DMN process orchestration. EDI X12/HL7/FHIR healthcare data exchange across 40+ integration flows. API Gateway governance (Apigee, Kong AI Gateway, Kong LLM Gateway, MuleSoft API Manager) enforcing OAuth 2.0/JWT and reducing API incidents by ~40%.

Reliability Discipline, Applied to AI. 15+ years owning SLIs, SLOs, and error budgets for mission-critical platforms at 99.99% uptime. I bring that same discipline to AI systems — treating model endpoints, prompt pipelines, and agent workflows as production infrastructure with the observability (OpenTelemetry, Datadog, Splunk, Dynatrace, Grafana) and incident rigor that implies.

Technical Leadership & Mentoring. As part of Optum's Technical Leadership Career Path, I set technical direction and lead architecture/design decisions for roughly 10 engineers and teams — spanning AI Gateway design, RAG pipeline architecture, and integration/reliability patterns. I lead complex integration efforts that require coordinating across multiple internal and external teams, and I mentor engineers on production-grade AI and integration practices so the standards I put in place hold up long after I've moved on to the next project.
